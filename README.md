# مقدمة إلى Java EE 5 / 6

👉 دورة تدريبية عبر الإنترنت:
[https://stahe.github.io/ar-javaee-juin-2012/](https://stahe.github.io/ar-javaee-juin-2012/)

## نظرة عامة

يقدم هذا الدليل التعليمي (يونيو 2012) مقدمة عملية لـ **Java EE** من خلال تطوير تطبيق **ثلاثي المستويات**:

* نظرة عامة
* منطق الأعمال
* الوصول إلى البيانات

يعتمد هذا المستند على Java EE 5 و 6 ويستخدم **مشاريع Maven**.

## التقنيات التي يتم تناولها

### تطبيق الويب

* JSF (Java Server Faces)
* EJB3 أو Spring (المستوى التجاري)
* JPA (Hibernate / EclipseLink)

### تطبيق العميل/الخادم

* Swing (عميل رسومي، دعم Spring)
* EJB3 أو خدمات الويب (الخادم)

## أهداف التعلم

* فهم بنية تطبيق Java المؤسسي
* مقارنة EJB3 و Spring
* تنفيذ JPA من أجل الاستمرارية
* إنشاء تطبيق كامل باستخدام NetBeans

يقدم هذا المستند نماذج للحلول ويترك للطالب مهمة إكمال بعض الأقسام.

## المتطلبات المسبقة

* معرفة بلغة Java
* بيئة تطوير متكاملة NetBeans (يُنصح بوجود ذاكرة وصول عشوائي (RAM) بسعة 1 غيغابايت تقريبًا)

## مراجع إضافية

* الاستمرارية في Java 5 في الممارسة العملية (JPA)
* مقدمة إلى لغة Java
* مقدمة إلى JSF / PrimeFaces
